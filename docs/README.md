- `site-architecture.md` — 設定、更新処理、公開ビルド、ブラウザ表示の構成
- `data-contract.md` — 保存・公開するVOD集計データの契約
- `PLAYBACK_SPEC.md` — Twitchプレイヤーと見どころ再生の仕様
